What is happening

An image can be described by pixels, but also by the soft repeating patterns that add up to those pixels. This page lets you draw on that hidden pattern layer, then rebuilds the image from it.

1. Draw the secretThe brown mark is placed where the image stores broad light and dark patterns.

2. Rebuild the pictureThe result still looks like the original image, but the mark can be seen when we inspect the hidden layer.

3. Try to damage itRotate, crop, draw over, or blur the rebuilt image to see whether the hidden mark survives.
